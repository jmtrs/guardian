# Guardian

Proyecto personal de vigilancia y telemetría para un coche de 12 V. Estado: **software de laboratorio**. La instalación en vehículo requiere un subsistema de alimentación automotriz protegido y verificado; el prototipo Python no es firmware real.

La placa prevista para la primera integración física es **LILYGO T-A7670E R2, versión europea CON GNSS (A7670E-FASE)**. La versión sin GPS no cumple el requisito de localización.

Los módulos actuales y la documentación se incorporarán mediante PR; no instalar en el coche hasta completar la etapa eléctrica y la autenticación local.
